# Terms

## Chapter 1

- //: indicates that whatever following this symbol is a comment. ignored by the compiler.
- function: a code block to do something with the arguments, probably returns something to its caller.
- output: prints something on the screen.
- compiler: a program for translating the source code we write to something a computer can execute.
- error: something that doesn't conform to C++ standard.
- linker: links the code I wrote with the code others' wrote the make the program run correctly.
- command line: use text instructions to tell the computer to do something.
- executable: a program that can be run directly by the computer.
- object code: the result of the compiler.
